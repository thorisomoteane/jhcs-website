# JHCS Website

The website for Jan Hofmeyer Community Services (JHCS), a registered NPO in
Johannesburg — public marketing pages plus an admin dashboard for managing
events, news posts, and volunteer applications.

Live: [jhcs-website.vercel.app](https://jhcs-website.vercel.app)

- **[ARCHITECTURE.md](./ARCHITECTURE.md)** — what the system is built from

- **[AGENTS.md](./AGENTS.md)** — Next.js-version-specific conventions for

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in Firebase config — see DEPLOYMENT.md
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Without a filled-in
`.env.local`, the site still runs — pages that need Firebase show a
"Firebase is not configured" message instead of crashing.

```bash
npm run lint     # ESLint
npm run build    # production build (also runs the TypeScript check)
```

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Firebase
(Firestore + Auth) · Vercel. Full details in `ARCHITECTURE.md`.
